# Warehouse and page display
UNAS frontend does not filter warehouses by product assignment the way the API does. Instead, it respects the VisibleOnProductDetails flag.
So if I have 4 warehouses, but i assign 2 warehouses for my product on the UNAS webshop i still will see all 4 warehouses.
To hide warehouses not assigned to the product, set the "Csak, ha van ezen a raktáron" flag to true.
